# 영진인슈로산업(주) 공식 홈페이지 리마스터

`http://youngjininsulro.co.kr/`의 시각적·기술적 전면 리마스터 프로젝트입니다.

- **라이브 사이트 (GitHub Pages):** https://technoetic.github.io/youngjin-insulro-remaster/
- **대상 법인:** 영진인슈로산업(주) (`139-81-20002`, 인천 남동국가산업단지 1단지 37B-6L)

## 주요 구현 사항

1. **극대화 시네마 히어로 (`#hero`)**
   - 브러시드 SUS 0.8T 방열문 시네마 비주얼 + 실시간 60fps HTML5 Canvas 극저온 냉기·결빙 입자 엔진 (`HeroVisualEngine`)
   - **라이브 BLDC 슬라이딩 방열문 시뮬레이터:** 개방/밀폐 원클릭 구동, 드래그 슬라이더(`0% ~ 100%`), 에어커튼 ON/OFF 연동, EPDM 기밀 잠금 플래시 및 실시간 ΔT·기밀 유지율·열 침입 부하 텔레메트리
   - **FLIR 열화상 X-Ray 모드:** 마우스 추적 열화상 스포트라이트 + 전체 열화상 모드 토글
   - **4단계 두께 선택 HUD:** `75mm(-10℃)` / `100mm(-25℃)` / `125mm(-30℃)` / `150mm(-40℃)`
2. **원 사이트 오류 100% 교정 & 19개 전 품목 재정비**
   - 타사 저작권 오기(`Owellsteel Corp`), 오타(`축전된 노하우`), 제철소·오븐/가정용 난방/가전 리모콘 오기 교정
   - `실적 준비중` 공백을 2025~2026 공공계약 검증 이력으로 보완하고, 미확인 인증·타사 특허는 일절 과장 표기하지 않음
3. **Webapp Principles 6원칙 준수**
   - 책임별 ES 모듈·클래스 경계, 3계층 CSS(`tokens/base/components`), `async/await` 경합·오류 처리, 해시 라우팅 및 404 분리, 콘텐츠 해시 자산 + `version.json` 기반 열린 탭 자동 배포 전환(작성 중인 견적 초안 보호)
